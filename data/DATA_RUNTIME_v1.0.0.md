# EvidentFolio 数据运行目录说明

- **目录**：`data/`
- **组件**：Runtime Data Storage
- **组件说明版本**：1.0.0
- **对应项目版本**：EvidentFolio 1.0.0

## 职责

该目录用于运行时持久化 SQLite 数据库、迁移前备份及相关数据文件。仓库只保留目录占位，不应提交真实业务数据库或备份文件。

## 数据边界

- 真实 SQLite 数据库属于运行时数据，不属于源码。
- `migration-backups/` 由启动迁移流程按需要创建。
- 该目录应在 Docker 或其他部署方式中持久化。
- 不应将访问记录、个人作品数据、AI 密钥或本地测试数据库提交到 Git。

## 运维要求

升级前保持原 `data/` 挂载路径；启动流程会执行 SQLite 完整性检查、必要备份和 Alembic 迁移。恢复数据时应同时确认数据库版本与上传资源的一致性。

## 版本约定

本说明对应项目 1.0.0 的数据目录语义。数据库 Schema 的真实版本由 Alembic revision 管理，而不是由本说明文件替代。
