# EvidentFolio 文档目录说明

- **目录**：`docs/`
- **组件**：项目文档
- **组件说明版本**：1.0.0
- **对应项目版本**：EvidentFolio 1.0.0
- **默认语言**：简体中文

## 目录职责

该目录集中保存架构、API、部署、项目结构以及文档截图等长期维护资料。根目录 `README.md` 负责快速入口，`docs/` 负责完整技术说明。

## 默认语言约定

- 不带语言后缀的 Markdown 文件默认使用简体中文。
- 英文版本统一使用 `.en.md`。
- 已存在的 `.zh-CN.md` 仅用于兼容旧链接时保留，不再作为默认入口。
- 目录说明和文件职责说明默认使用中文。

## 文档索引

- `ARCHITECTURE.md`：默认中文系统架构、运行边界、数据与安全设计。
- `ARCHITECTURE.en.md`：英文系统架构说明。
- `API.md`：默认中文 API 使用说明。
- `API.en.md`：英文 API 使用说明。
- `DEPLOYMENT.md`：默认中文部署、升级、备份与回滚说明。
- `DEPLOYMENT.en.md`：英文部署说明。
- `DEPLOYMENT.zh-CN.md`：旧中文链接兼容入口。
- `PROJECT_STRUCTURE.md`：默认中文仓库目录与文件职责映射。
- `PROJECT_STRUCTURE.en.md`：英文项目结构说明。
- `images/`：经过脱敏的项目文档截图。

## 维护原则

代码行为变化但文档未同步会产生额外维护成本。涉及 API、配置项、启动流程、目录职责、迁移策略或部署方式的变更，应在同一 PR 中更新对应中文默认文档；若存在英文版本且相关内容发生变化，也应同步维护。

## 版本约定

该文档索引对应 EvidentFolio 1.0.0。单个文档可持续更新，但涉及发行版可见行为变化时应同时更新 `CHANGELOG.md`。
